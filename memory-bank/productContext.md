# NODE 01: Product Context (The Market Vector)

## Target User Psychology
- **Greed:** Crypto airdrop qualification, token farming, 60s binary prediction gambling.
- **Paranoia:** Leaked credentials, data breach exposure, legal contract vulnerabilities.
- **Lust / Loneliness / Ego:** Uncensored parasocial AI companionship, premium visual renders, social clout.

## UI/UX Friction Points
- Zero external sign-up / login forms: Telegram `initData` provides immediate cryptographic identity.
- Frictionless checkout: Native Telegram Stars (Apple Pay / Google Pay) and 1-tap TON Connect wallet integration.
- Dark-mode default, mobile-first responsive viewport matching native Telegram client look and feel.
- Instant feedback loops: Tollbooths trigger directly at point of maximum user desire or fear.

## Core Problem Resolved
- Eliminates standard Web2 onboarding drop-off and checkout fatigue by converting high-intent Telegram users directly into paying customers through native micro-tollbooths inside Telegram Mini Apps.
